🎮 IT Brzo Test
IT Brzo Test je interaktivna edukativna igra razvijena u Unity engine-u, namenjena deci uzrasta 10+ godina, kao i svima koji žele da na zabavan način provere i prošire svoje osnovno IT znanje.

Inspirisana retro pixel-art estetikom i arkadnim sistemima borbe, igra kombinuje učenje sa dinamikom igranja!

✨ Ključne Karakteristike
Edukativni kviz: Pitanja prilagođena mlađim uzrastima koja pokrivaju osnove informike i opšteg IT znanja (hardver, softver, osnovni pojmovi).

Dinamične animacije: Oživljeni pixel-art likovi (junak i skelet) koji prate tok igre i odgovore igrača kroz vizuelne animacije.

Health / Life Bar: Funkcionalni sistem zdravlja koji prati napredak i tačnost odgovora u realnom vremenu.

Retro Pixel Stil: Vizuelni identitet inspirisan klasičnim 2D igrama sa čistim i preglednim interfejsom.

🛠️ Tehnologije i Alatke
Game Engine: Unity (C#)

Grafika/Stil: 2D Pixel Art

Platforma: Desktop (Windows)

🚀 Kako pokrenuti projekat
Kloniiraj repozitorijum na svoj računar ili ga preuzmi kao ZIP fajl.

Otvori Unity Hub.

Klikni na Add i izaberi folder sa projektom (projekat je podešen za rad u Unity-ju).

Otvori scenu, pritisni Play i testiraj svoje IT znanje!
